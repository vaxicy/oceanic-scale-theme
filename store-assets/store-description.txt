Oceanic Scale Theme brings a washed sea-glass palette to VS Code in two coordinated variants. The light theme reads like mint-tinted paper with slate-teal ink, sage accents and a hint of pressed-flower mauve; the dark theme is the same desk at dusk, built on deep sea glass. Both share one palette, so switching changes only the light level. Every surface is themed — editor, sidebar, tabs, status bar, terminal ANSI colors, buttons, badges, git decorations and semantic tokens — with 144 UI colors per variant and readable syntax colors for keywords, strings, numbers and types.
